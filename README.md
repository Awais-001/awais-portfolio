# Awais Raza — Portfolio

Next.js 15 + Tailwind CSS 4 + Motion. Static export (works on Vercel, Netlify or any static host).

## Run it locally
1. Install Node.js 20+ from nodejs.org
2. In this folder run:
   npm install
   npm run dev
3. Open http://localhost:3000

## Where things live
- `src/lib/site.ts` — your email, LinkedIn, Behance and resume links (replace the "#" links)
- `src/lib/projects.ts` — the five homepage project cards
- `src/components/home/` — homepage sections
- `public/images/` — optimized project images (WebP)

## Build
   npm run build   → static site in the `out` folder
